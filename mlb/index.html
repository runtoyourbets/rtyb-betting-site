Run To Your Bets MLB First Inning & First Five Betting

▾

Run To Your Bets is built for MLB first innings and first fives. Baseball's early bets come down to one thing: the starting pitchers. The first inning is starter vs starter against the top of each lineup. The first five is starter vs starter before the bullpens show up. Bets settle in about 15 to 20 minutes for the first inning and about an hour and a half for the first five.

What's on this page

  • Matchup of the Day: the game with the most trends lining up today, and the price to play it.
  • Streaks to Watch: teams on a run of 3 or more in a row, with a game today.
  • The Big Numbers: the heaviest first five favorite, the highest F5 total and the priciest NRFI on the board.
  • The Slate: every MLB game today with its first inning and first five lines, then the scores as they go final.

Every record on Run To Your Bets is graded at the closing line, the last price before the game starts, and every number is updated every 10 minutes.

FAQ

What does NRFI mean?

No Run First Inning: neither team scores in the 1st. YRFI (Yes Run First Inning) is the other side: at least one run scores.

Do bullpens matter for first five bets?

Mostly no. That's the point of the first five: it's starter against starter. If a starter gets pulled early, the bullpen counts, so check how deep each starter usually goes.

What happens if the first five ends tied?

A 2-way F5 moneyline usually pushes. On the F5 run line, the +0.5 side wins.
