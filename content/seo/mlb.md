## FAQ

### What does NRFI mean?

No Run First Inning: neither team scores in the 1st. YRFI (Yes Run First Inning) is the other side: at least one run scores.

### Do bullpens matter for first five bets?

Mostly no. That's the point of the first five: it's starter against starter. If a starter gets pulled early, the bullpen counts, so check how deep each starter usually goes.

### What happens if the first five ends tied?

A 2-way F5 moneyline usually pushes. On the F5 run line, the +0.5 side wins.
